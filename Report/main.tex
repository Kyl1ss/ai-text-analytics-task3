\subsection{Data Preprocessing and Dataset Preparation}

The dataset used in this project contains arXiv abstracts from the \texttt{cs.LG} category, which represents machine learning research. The original filtered dataset contained 7,015 records and five main columns: paper ID, title, abstract, categories, and publication year. The papers cover the period from 1999 to 2021, allowing us to analyse how machine learning research topics have changed over time.

Before applying text analytics methods, we cleaned and prepared the dataset. First, duplicate abstracts were removed to avoid counting the same research content more than once. This removed one duplicated record, leaving 7,014 papers in the final dataset. We also checked for missing values in the key fields, including paper ID, abstract, and year. No missing values were found in these columns.

The abstract text was then normalised. Extra whitespace was removed, and all text was converted to lowercase. Punctuation was removed, hyphenated terms were separated, and the abstracts were tokenised using NLTK. English stopwords were removed to reduce the influence of very common words that are unlikely to represent meaningful research themes. The cleaned version of each abstract was stored in a new column, \texttt{cleaned\_abstract}, while the original abstract was also retained for reference and interpretation.

In addition to text cleaning, we created several useful metadata features. The year column was converted to integer format, and two length-based features were calculated: word count and character count. These features were used for exploratory analysis, especially to compare whether abstract length varied across different time periods.

To support temporal analysis, each paper was assigned to one of four research periods: \textit{early} (1999--2009), \textit{mid} (2010--2014), \textit{growth} (2015--2017), and \textit{recent} (2018--2021). This grouping was used because the number of papers varies substantially across years. Grouping years into broader periods helps reduce yearly noise and makes long-term topic changes easier to interpret.

The final dataset contained 7,014 abstracts. The period distribution was uneven: 150 papers belonged to the early period, 724 to the mid period, 1,488 to the growth period, and 4,652 to the recent period. This imbalance reflects the rapid expansion of machine learning research on arXiv, especially in the most recent years.

For model development and evaluation, the dataset was split into training, validation, and test sets using a 70/15/15 split. Stratified sampling was applied based on the period label to preserve the temporal distribution across the three splits. This produced 4,909 training examples, 1,052 validation examples, and 1,053 test examples. The training set was used to fit models, the validation set was used for model selection and parameter tuning, and the test set was reserved for final evaluation.

Finally, several processed files were saved for use by other parts of the project, including the full cleaned dataset, the train/validation/test splits, and separate CSV files for each time period. An overview figure was also generated to show the number of papers per year, the distribution of papers across periods, and the abstract word count distribution by period.

\subsection{Text Representation and Baseline System}

After preprocessing the dataset, the abstracts were converted into numerical representations so that they could be used for downstream text analytics and machine learning methods. Since the aim of this project is to analyse how machine learning research has changed over time, we compared three different text representation methods: TF-IDF, Word2Vec, and Sentence-BERT. These methods were selected because they capture different aspects of the abstracts, from surface-level vocabulary changes to deeper semantic relationships.

The first representation was TF-IDF, which was used as the baseline representation. TF-IDF represents each abstract as a sparse vector of term importance scores. A term receives a high score if it appears frequently in a specific abstract but is relatively uncommon across the whole corpus. This makes TF-IDF useful for identifying distinctive vocabulary in different time periods. In this project, both unigrams and bigrams were included using an n-gram range of $(1,2)$. This was important because many machine learning concepts are expressed as multi-word phrases, such as \textit{deep learning}, \textit{support vector}, and \textit{reinforcement learning}. English stopwords were removed, and a token pattern was used to keep alphabetic terms with at least three letters, reducing noise from numbers and very short tokens.

In addition to fitting TF-IDF on the full corpus, separate TF-IDF models were also fitted for each time period: \textit{early}, \textit{mid}, \textit{growth}, and \textit{recent}. This allowed us to identify the most distinctive terms within each period. The aim was not only to represent documents for modelling, but also to make vocabulary shifts over time more interpretable. For example, earlier periods were expected to contain more classical machine learning terms, while later periods were expected to show increased use of terms related to neural networks, deep learning, graph-based methods, and other recent research directions.

A count matrix was also created using the same vocabulary settings as the TF-IDF vectorizer. Unlike TF-IDF, the count matrix stores raw word frequencies. This representation was prepared because topic modelling methods such as LDA require raw word counts rather than weighted TF-IDF values. Keeping the same tokenisation and n-gram settings helped make the count-based and TF-IDF-based analyses more comparable.

The second representation was Word2Vec. Unlike TF-IDF, which treats words mainly as independent frequency-based features, Word2Vec learns dense word embeddings based on the surrounding context of each word. Words that appear in similar contexts are placed closer together in the vector space. This is useful for this project because related machine learning concepts may be expressed using different but semantically related terms. The Word2Vec model was trained directly on the cleaned arXiv abstracts, allowing it to learn domain-specific relationships within the machine learning corpus. Each abstract was then represented by averaging the vectors of all words in the abstract. This produced a 100-dimensional vector for each document.

The Word2Vec representation was also checked qualitatively by inspecting similar words for key machine learning terms. For example, terms related to neural networks, reinforcement learning, and Bayesian methods appeared close to related concepts and abbreviations. This suggests that the model captured meaningful relationships within the corpus. However, because the Word2Vec model was trained only on this dataset, it may be less reliable for rare or highly specialised terms.

The third representation was Sentence-BERT. Sentence-BERT encodes the entire abstract as a single dense vector, rather than building a document vector from individual word vectors. We used the \texttt{all-MiniLM-L6-v2} model, which produces 384-dimensional sentence embeddings. This representation was included because it can capture the overall semantic meaning of an abstract more effectively than purely frequency-based methods. This is especially useful when papers from different periods discuss similar research problems using different terminology.

The three representations therefore serve complementary purposes. TF-IDF is the most interpretable and is useful for identifying clear vocabulary changes across time. Word2Vec captures semantic relationships between machine learning concepts and can show connections between related methods. Sentence-BERT provides the richest document-level semantic representation and is useful for identifying conceptually similar papers even when they come from different time periods. Together, these representations allow the project to analyse both surface-level vocabulary shifts and deeper changes in the semantic structure of machine learning research.

The main outputs from this stage were a TF-IDF matrix, a count matrix, Word2Vec document embeddings, and Sentence-BERT document embeddings. These files were saved for use in later comparison, topic analysis, dimensionality reduction, and evaluation stages.
